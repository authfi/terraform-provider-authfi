# Changelog

All notable changes to this provider. It follows [Semantic Versioning](https://semver.org): before 1.0 a minor
version may break, but only with an entry here.

## 0.1.0

The first release, published to the Terraform Registry as `authfi/authfi`.

### Added

- Resources: `authfi_project`, `authfi_organization`, `authfi_application`, `authfi_connection`, `authfi_domain`,
  `authfi_branding`, `authfi_user`, `authfi_group`, `authfi_group_member`, `authfi_group_role`, `authfi_role`,
  `authfi_permission`, `authfi_role_permission`, `authfi_user_role`, `authfi_cloud_account`,
  `authfi_cloud_mapping` and `authfi_scim_target`.
- Release archives for Linux, macOS, Windows and FreeBSD, with a SHA-256 checksum file signed by the release key
  and a build provenance attestation.
